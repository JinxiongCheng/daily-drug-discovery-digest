# 2026-11-04 · 周三 · 单细胞与扰动生物学

## 论文

### Predicting cellular responses to perturbation across diverse contexts with STATE

Abhinav Adduri, Dhruv Gautam 等;通讯 Yusuf Roohani, Hani Goodarzi(Arc Institute)· bioRxiv 预印本,2025-06-26(二级信源称后刊于 *Cell*,2026,期刊版细节未独立核实)
DOI:10.1101/2025.06.26.661135 · https://www.biorxiv.org/content/10.1101/2025.06.26.661135v2

**核心主张**:给定对照细胞状态和一个扰动的编码,直接预测扰动后单细胞转录组分布的"虚拟细胞"模型,号称是第一个在多数据集上稳定超过简单线性基线的扰动预测模型。

**方法**:两段式。State Embedding(SE)用约 1.67 亿个未扰动的观测性单细胞转录组预训练,学出一个能跨实验、跨细胞类型迁移的细胞嵌入空间;State Transition(ST)用超过 1 亿个扰动后细胞(Tahoe-100M、Replogle-Nadig 等数据集,约 70 个细胞系)训练,输入"对照细胞 embedding + 扰动 one-hot 向量",输出扰动后细胞在同一嵌入空间里的位置,再解码回表达谱。推理时靠 SE 学到的跨 context 共性,对训练里没见过的"细胞类型 × 扰动"组合做泛化。配套发布 Cell-Eval 评估框架和 Perturbation Discrimination Score(PDS)指标。

**关键数字**:老实说——bioRxiv 和 arcinstitute.org 在这个环境里都被拦截,原文打不开。三个独立二级信源给出的"相对基线提升幅度"互相不一致(有说 PDS 提升超过 30%,有说超过 50%,还有中文二级报道给出 Tahoe 上 Pearson 相关性超基线 **63%**、PBMC 上 **47%**),彼此不吻合,没有一个能在原文核实到,所以不把它们当确定数字写进来。能核实到的是训练规模(约 **1.67 亿**观测细胞 + 超过 **1 亿**扰动细胞,约 **70** 个细胞系)和"号称第一个稳定超过线性基线"这条定性说法——这条本身也是作者自报,没查到第三方复现验证。

**最大方法学弱点**:PDS 这类"距离排序"指标容易被模式坍塌(mode collapse)骗过——模型只要稳定输出一个大致合理的"平均扰动后表达谱",排序类指标也能打高分,不代表真的区分出了不同扰动各自的特异效应。这不是我猜的,是另一篇 2025 年的 bioRxiv 文章(arXiv:2506.22641,*Diversity by Design*)专门论证的,State 用的评估框架正好落在它批评的范围内。

**接口**:弱。State 预测的是转录组,我的数据是形态/图像读出(PGCC 形态筛选、相差显微镜迁移轨迹),读出层完全不同,没有现成桥梁;但它"对照 embedding + 扰动向量 → 预测 post-perturbation 分布"这套建模范式是通用的,值得借到图像端。

**谁在做**:Arc Institute(Roohani/Goodarzi 组,State/Stack)目前最高调;同赛道还有 Tahoe Therapeutics(提供 Tahoe-100M 数据)、Chan Zuckerberg Biohub、Xaira Therapeutics(X-Cell)、学界的 Jure Leskovec 组(GEARS,Stanford)。

## 新闻 + 历史对照

Anthropic 在 2026-10-27 发布更新,披露与 6 家药物研发机构(Enveda、Generate Biomedicines、Divergence Labs、BigHat Biosciences、Bristol Myers Squibb、The Column Group)用 Claude 做真实项目的早期合作结果。Generate Biomedicines 团队用 Claude Code 辅助重新设计 CAR-T 的部分基因序列组件,目标是把现在主要用于血液瘤的 CAR-T 推向实体瘤。报道的数字:一个重新设计构件比标准版本短约 **70%**,实验室测试中让免疫细胞表达的肿瘤识别受体数量约为标准设计的 **10 倍**,杀伤能力和存活时间也有改善。没找到样本量、统计检验方式,也没有体内或临床数据。

**AI 真实含量**:是真的,不是文档层面的噱头——用 Claude Code 生成候选序列设计是这个结果的核心步骤。但这是体外结果,没有同行评审论文,信息全部来自 Anthropic 自己的博客和媒体转载,没有第三方独立验证。

**历史对照**:"AI 设计候选物在实验室表现亮眼、还没进临床"这一步,历史上大多数 AI 制药叙事都卡在这里——2020 年前后 Exscientia、BenevolentAI 公开的早期"AI 设计分子"案例多数体外/动物阶段表现不错,进入临床后照样被 PK、毒性、剂量问题筛掉;CAR-T 工程改造史上,体外受体表达量和杀伤力增强,也不必然带来体内持久性和疗效,这个落差反复出现。
