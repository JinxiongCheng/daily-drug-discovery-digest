论文

Predicting cellular responses to perturbation across diverse contexts with State

Abhinav K. Adduri、Yusuf H. Roohani 等（Arc Institute，完整作者名单没核实到）· Cell，2026-08-31 在线发表 · DOI:10.1016/j.cell.2026.07.052（bioRxiv 预印本 2025-06-26，10.1101/2025.06.26.661135）· https://doi.org/10.1016/j.cell.2026.07.052

核心主张：一个两阶段架构——先学一个细胞状态空间的表征，再学扰动怎么把细胞从状态空间里的一个点推到另一个点——在跨 70 个细胞背景的大规模扰动数据上训练后，预测细胞对遗传、化学、细胞因子扰动转录组响应的能力全面超过已有方法。

方法：State Embedding（SE）模块用约 1.67 亿个未扰动细胞的观测转录组做自监督预训练，把表达谱映射到一个对批次噪声更鲁棒的向量空间，同类型细胞聚簇。State Transition（ST）模块用超过 1 亿个扰动细胞、跨 70 个细胞背景训练一个以扰动身份为条件的转移函数，预测细胞在这个状态空间里的位移，解码后得到预测表达谱。训练和评估都是"一批细胞对一批细胞"的 set 级别匹配，不是逐细胞配对。

关键数字：官方通稿称 STATE 把扰动效应判别力（discrimination）提升超过 50%，识别真实差异表达基因的准确率是现有模型的 2 倍以上。这两个数字只能核实到 Arc Institute 官方转述（含一条官方推文原话），具体对比哪个 baseline、在哪个数据集、用什么统计口径算出来的，今天没核实到。

方法学最大弱点：相对提升数字容易掩盖跟谁比。9/16 那篇论文已经证明，在扰动预测这个任务上，一个什么都不学的 mean baseline 经常打平甚至反超 scGPT 这类深度模型；如果 STATE 挑的对照组是同一批早期 foundation model 而不是调好的线性/均值 baseline，"2 倍"的意义要打折扣。更实质的边界是：Arc 自己后续发布的 Stack 模型，明确是为了解决"STATE 需要目标 cell context 里已有扰动训练数据才能预测"这个限制，这反过来说明 STATE 在完全没见过的新 context 上零样本泛化能力有限。

接口：弱。STATE 处理 scRNA-seq 转录组，你的数据是相差显微镜图像和形态学筛选，模态不同，没法直接套用。可以借鉴的只是设计思路——先学状态空间表征、再学条件化转移——如果以后想做"形态学状态空间 + 扰动条件转移"的类似物，这是个参考模板。

谁在做：学界 Stanford（Roohani/Leskovec 一脉，GEARS 也出自这里）、Regev 实验室（Genentech/MIT）、Theis 实验室（Helmholtz Munich）。产业 Arc Institute、Genentech、Recursion，以及专门做超大规模 Perturb-seq 数据集的 Tahoe Therapeutics（Tahoe-100M）。

五分钟判断题（数字体检）

STATE 的 ST 模块号称覆盖 70 个细胞背景、超过 1 亿个扰动细胞，平均每个 context 约 140 万个扰动细胞。主流公开 Perturb-seq 数据集（比如 Replogle 2022 全基因组 CRISPRi 筛选）单个数据集通常是多少细胞量级？如果明显小于 140 万，这个均值说明了什么——70 个 context 是不是被一两个超大规模数据集严重拉高，导致大多数 context 实际训练数据很稀疏？

新闻 + 历史对照

AbbVie 和 Iambic Therapeutics 于 2026-09-21 宣布多年期研究合作，聚焦小分子药物发现，覆盖免疫、神经科学、肿瘤三个治疗领域。Iambic 把它的平台——多模态 transformer 模型 Enchant v3（号称训练于 6000+ 分子性质）、蛋白-配体复合物结构生成模型 NeuralPLexer、加内部高通量湿实验闭环——接入 AbbVie 的治疗领域专长。Iambic 将获得首付款，并有资格拿基于里程碑的付款和净销售额分成；首付款、里程碑总额、分成比例、涉及项目数，双方均未披露，没查到就是没查到。

AI 含量：这是发现阶段的平台合作，不是临床数据，也没有已验证的先导化合物。AI 的"贡献"目前只存在于合作意向层面——Iambic 声称平台能提高候选药物成功率，这类声明在签约当天永远无法验证，只有项目走到临床甚至获批才能检验。这条新闻本身不能当作"AI 在药物研发里有效"的证据，只能算"大药厂仍愿为 AI 平台的期权买单"的证据。

历史对照："平台合作+里程碑付款、财务条款不披露"是过去十年 AI 药物发现领域反复出现的公告模式。签约通稿密集描述技术能力，几乎从不披露能验证有效性的对照数字（命中率提升多少、周期缩短多少）；等到合作到期或项目终止，后续报道的关注度远低于签约当天。签约时刻的叙事总是被放到最大，终止或沉寂时刻的叙事总是被缩到最小，这正是判断这类新闻时最该警惕的偏差。
