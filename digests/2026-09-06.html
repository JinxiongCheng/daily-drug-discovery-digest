Data Leakage and Redundancy in the LIT-PCBA Benchmark

Amber Huang, Ian Scott Knight, Slava Naprienko
arXiv:2507.21404（2025年7月）· https://arxiv.org/abs/2507.21404

核心主张：虚拟筛选领域被广泛使用的 LIT-PCBA 基准存在系统性数据泄漏和结构冗余，足以让一个不含可学习参数的记忆式方法打平甚至超过已发表的 SOTA 深度模型，这个基准不能再被当作公平的评测标准用。

方法：作者对 LIT-PCBA 15 个靶点的 training / validation / query 三个 split 做 2D 结构层面的稽核——用 ECFP4 指纹做精确匹配找完全重复分子，用 Tanimoto 相似度找近重复（analog）。检查三类问题：(1) 跨 split 泄漏，同一分子同时出现在不该同时出现的 split 里；(2) 单个 split 内部的重复；(3) query set（本该代表“未见过”的测试用例）里混进了训练/验证集里出现过的配体。然后构造一个零参数 baseline：对每个 query 分子，用它到 training actives 的最大 2D ECFP4 Tanimoto 相似度直接作为筛选打分，跑一遍标准的 EF1%（前 1% 富集因子）评测，和文献里已发表的 3D encoder 方法的数字放在一起比。

关键数字：跨 split 重复 inactive 分子 2,491 个；training 内部重复 2,945 个，validation 内部重复 789 个；query set 里 3 个配体本应是“未见过”的测试样本，实际 2 个出现在 training、1 个出现在 validation；ALDH1 靶点上有 323 对 Tanimoto ≥ 0.6 的 active 高相似对跨越 train/val；MTORC1 靶点 11 个 query 配体里 9 个是 Tanimoto ≥ 0.9 的近重复。零参数的最大相似度 baseline，只用 training actives 时 EF1% 中位数 = 4.15，与近期发表的 3D encoder 方法报告的水平相当；把 query 配体也纳入相似度比较池后中位数升到 4.33，均值从 4.35 升到 5.83。

最大方法学弱点：文章论证“简单 baseline ≈ SOTA”的方式，是把自己跑出来的 baseline EF1% 数字和其他论文里报告的 SOTA 数字直接摆在一起比较，而不是在完全相同的评测代码、相同负样本采样、相同 EF 定义下重新跑一遍 SOTA 模型。跨论文的数字对比很容易因为口径差异（负样本怎么定义、EF 怎么算）产生误导，这个“打平”结论目前还不是受控实验意义上的打平。

和我的课题接口：没有直接接口。我目前不做化合物库虚拟筛选，但这提醒我以后如果做任何 molecule-side 的工作，在划 train/test 前必须先对基准或自建数据集做类似的 2D 去重稽核，不能默认公开基准是干净的。

谁在做：这类“基准审计/方法学批评”的工作目前集中在学界做评测方法学的小团队和独立研究者手里，和产业界关系不大——审计自己行业标杆数据集，对靠这些基准打榜融资的商业化虚拟筛选公司是负向激励，很少见到大药厂或 AI 药物发现公司主动发这类论文。

五分钟判断题（找死穴）

审计判定“重复/冗余”的标准是 2D ECFP4 精确匹配（完全重复）+ Tanimoto 阈值（如 0.6、0.9，近重复）。如果把“近重复”这条标准去掉，只保留“2D 结构完全一致”才算泄漏，他们的核心结论——零参数 baseline 打平 SOTA——还能不能站得住?具体说说数字会怎么变。

新闻 + 历史对照

2026 年 9 月 3 日，Akeso 宣布其 III 期 HARMONi-2（AK112-303）试验的 OS（总生存期）期中分析，经独立数据监察委员会（IDMC）评估，达到了关键次要终点。HARMONi-2 是一项全球注册性 III 期试验，评估 ivonescimab（PD-1/VEGF 双特异性抗体）单药对比 pembrolizumab 单药，一线治疗 PD-L1 阳性（TPS≥1%）局部晚期/转移性 NSCLC。公司只说“具有统计学意义且临床意义显著”，没有公布具体 HR、中位 OS 或 p 值，称会在后续会议和同行评审期刊上公布——这部分数字目前查不到，不做估计。作为参照，该试验此前公布的主要终点（PFS）数据是：中位 PFS 11.14 个月 vs pembrolizumab 组 5.8 个月，HR = 0.51，P < .0001。（链接）

AI 含量：Akeso 官方资料里把“AI-powered drug R&D platform”列为公司多个技术平台之一，但 ivonescimab 本身的工程化基础是公司的 Tetrabody 双特异性抗体骨架平台，没有公开证据显示这款分子的发现或优化流程具体用到了 AI/ML 方法。公司泛化的“AI 平台”宣传语不能当作这款药有实质 AI 含量的证据——就这条新闻而言，AI 贡献不明确，大概率很小，不做夸大。

历史对照：VEGF 通路阻断和 PD-1/PD-L1 检查点阻断联用治疗 NSCLC 的临床假说，在 2018 年的 IMpower150 试验（atezolizumab + bevacizumab + 化疗 vs bevacizumab + 化疗，NEJM）里首次被 III 期数据证实能带来 OS 获益，建立了“VEGF + 免疫检查点联合阻断”这条路线的合法性。Ivonescimab 把两种机制做进同一个双特异性抗体分子里，某种意义上是把 IMpower150 验证过的联合机制假说做了一次分子工程化的延续，不是全新机制的首次验证。
